# 🎲 증강 윷놀이

최대 4인 온라인 멀티플레이 윷놀이. 1·6·12라운드에 증강을 고르고(총 3개), 혼돈 모드에서는 한 번에 2개씩 고릅니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

- 한 사람이 "새 방 만들기" → 4글자 방 코드를 친구에게 공유 → 친구들은 같은 주소로 접속해 코드 입력.
- 같은 와이파이라면 `http://<내 PC IP>:3000` 으로 접속.
- 밖에서 친구들과 하려면: 임시로는 `npx cloudflared tunnel --url http://localhost:3000` (또는 ngrok),
  계속 쓰려면 Render / Railway / Fly.io 같은 곳에 이 폴더를 올리고 시작 명령을 `npm start` 로 설정 (PORT 환경변수 자동 사용).

## 구조

| 파일 | 역할 |
|---|---|
| `game.js` | 모든 규칙(윷판, 이동, 잡기, 증강 선택, 증강 효과, 승리 조건). 서버가 판정하므로 치팅 불가 |
| `server.js` | HTTP + WebSocket, 방 관리, 재접속(토큰) |
| `public/index.html` | 화면 전체 (로비, 윷판 SVG, 증강 선택, 능력 사용) |
| `test/sim.js` | 봇 시뮬레이션: `npm test` |
| `test/e2e.js` | 서버+WebSocket 통합 테스트: `node test/e2e.js` |

8톤 트럭, 3단 합체 필살기, 게임 접어라, 거머리, 나 누구게?, 내려, 돌려돌려 돌림판, 변환: 도깨비/포/폰, 안개, 알까기, 언제부터 착각한 거지?, 윷을 잘 던져봐, 천마군림보, 말이오? 파티, 시작 변환: 김첨지/중전마마, 계획대로, 나에게 윷놀이는 "살인"이다, 네크로맨서, 동메달도 잘한 거야, 메아리의 형상, 승부다!, 영역 전개, 취~소, 카니발리즘

증강 추가는 `game.js` 의 `AUGMENTS` 에 항목을 넣고, 효과를 `acquire()`(즉시 효과), `actAbility()`(사용 능력), `winReason()`(승리 조건), `actThrow()`/`actMove()`(규칙 변경) 중 알맞은 곳에 붙이면 됩니다.

## 기본 규칙 / 해석한 부분 (바꾸고 싶으면 알려주세요)

- 윷판: 출발점에서 반시계로 이동, 모서리(5·10)에 멈추면 지름길 진입, 출발점에 닿거나 지나면 완주. 중앙에서 출발하면 출발점 쪽 길.
- 윷 4개 기준 도/개/걸/윷/모, 도 중 1/4은 백도. 윷·모, 말 잡기 시 한 번 더 던짐. 던질 기회를 다 쓴 뒤 결과를 골라 이동.
- 같은 칸의 내 말은 자동으로 업힘(말뭉치). 말이 잡히면 대기칸으로 돌아감.
- 가장 먼저 모든 말을 완주시키면 승리. 증강 승리 조건은 즉시 승리. 탈락자만 남으면 마지막 생존자 승리.
- 증강 선택은 자리 순서대로, 각자 3개 중 1개(혼돈 모드는 연속 2번). 자기가 이미 가진 증강은 나오지 않음.
- **과유불급**: 앞면 1개=도, 2개=개, 3·4개=걸 (원문 각주가 없어 임의 지정).
- **천상천하 유아독존**: 대기 말 없이 남은 말 전부가 하나의 말뭉치일 때 승리 (그냥 말뭉치 1개면 첫 수에 바로 이겨서).
- **웅녀**: 마늘 칸을 지나가기만 해도 획득.
- **도베르만**: 획득 시 지금까지 낸 개 수만큼 코인, 이후 개를 낼 때마다 +1. 던질 때 버튼으로 코인 2개를 써서 모.
- **명사수**: 던질 기회 1회를 쓰고 칸 선택(다른 사람에겐 비공개). 다음 내 차례 시작 때 그 칸의 모든 말(내 말 포함) 사망.
- **히히 똥**: 한 번 밟히면 사라짐.
- 보호막이 막은 경우 공격자는 같은 칸에 함께 서게 됩니다(서로 다른 색은 공존).
