# 🎲 증강 윷놀이

최대 6인 온라인 멀티플레이 윷놀이. 1·5·10라운드에 증강을 고르고(총 3개), 혼돈 모드에서는 한 번에 2개씩 고릅니다.
증강 목록의 **모든 증강(71개)** 이 구현되어 있습니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

방장이 "새 방 만들기" → 4글자 방 코드를 공유 → 친구들은 같은 주소로 접속해 코드 입력. 로비/게임 화면의 "방 나가기"로 나갈 수 있습니다 (게임 중 나가면 탈락 처리).

## 배포 (Render) 업데이트 방법
GitHub 저장소에 바뀐 파일(`game.js`, `server.js`, `public/index.html`, `README.md`, `test/`)을 덮어 올린 뒤, Render의 서비스 화면에서 **Manual Deploy → Deploy latest commit**.

## 모드
- **혼돈 모드**: 증강을 한 번에 2번 고름.
- **순위전**: 한 명이 이겨도 끝나지 않고 순위를 끝까지 가림. 이 모드에서만 *계획대로, 동메달도 잘한 거야, 취~소* 증강이 나옴. (꺼져 있으면 첫 승리 즉시 종료)
- 40라운드가 넘도록 안 끝나면 시간 종료 → 진행도(완주 수, 말 위치)가 높은 순으로 순위.

## 해석한 부분 (원문이 모호해서 정한 것 — 바꾸고 싶으면 알려주세요)
**기본**
- 증강 선택: 1라운드=시작 전용+범용, 5라운드=중간 전용+범용, 10라운드=마무리 전용+범용. 전용 증강은 해당 선택에서만 등장.
- 증강 선택은 **모든 플레이어가 동시에** 합니다(남의 선택지·선택은 비공개). 모두 고르면 선택이 공개되고, 명탐정이 먼저 처리되어 지목한 증강을 (명탐정 본인 외) 다른 사람들이 고른 것에서 무효화한 뒤, 차례 순서대로 효과를 적용합니다.
- 게임 시작 전 모든 플레이어가 윷을 던져 큰 순서(모>윷>걸>개>도>백도)대로 차례가 정해집니다. 동점이면 동점자끼리 다시 던집니다.
- 윷 4개 기준, 도 중 1/4은 백도. (윷 개수가 달라지면 5개: 윷·모가 드물고 개가 많이 나옴 / 3개: 걸이 없고 윷·모가 자주 나옴) 윷·모·말 잡기는 한 번 더. 던질 기회를 다 쓴 뒤 결과를 골라 이동. 같은 칸의 내 말은 자동으로 업힘.
- 승리: 모든 말 완주 또는 증강 승리 조건 달성.
- 과유불급: 앞면 1개=도, 2개=개, 3·4개=걸. / 천상천하 유아독존: 대기 말 없이 남은 말 전부가 하나의 말뭉치일 때.
- 웅녀: 마늘 칸에 **정확히 멈춰야** 획득. 지나가면 그 칸의 위치만 나에게 표시됨.
- 등가교환: 말 1개 제거 + 윷 1개 추가(5개). / 짐덩이와 복덩이: 말 1개 추가 + 윷 1개 제거(3개).
- 모 아니면 도: 모 40% / 도 60%. / 이도류: 모가 나오면 도로 바뀌며, 바뀔 때마다 알림이 뜸.

**새로 추가한 증강**
- **8톤 트럭**: 던지기 전에만 사용. 지금 가는 방향의 **직선**을 따라 달리다가 다른 말(누구든)이 있는 칸 앞이나 **벽(그 직선의 끝, 모서리·대각선 끝)** 에서 멈춤(잡지 않음). 모서리를 돌아 이어 가지 않음. 차례 소모.
- **3단 합체 필살기**: 던지기 전에만. 선택한 말뭉치 외의 모든 말뭉치(내 것 포함) 사망. 차례 소모.
- **게임 접어라**: 접히는 쪽의 말이 반대편 대칭 칸으로 옮겨가며 거기 있던 적을 잡음. 출발점(0)으로 접히면 골인 처리.
- **돌려돌려 돌림판**: 시계 반대 방향 90°×(1~3) 회전, 말이 5칸씩 이동(출발점에 닿으면 골인). 소유자가 1회 다시 돌릴 수 있음.
- **거머리**: 대기 중인 말을 우선으로 1개 넘겨줌. 상대가 이기면 같이 이기고, 탈락하면 같이 탈락.
- **나 누구게?**: 모든 말·이름 색이 회색이 되고, 나를 뺀 모든 플레이어가 자기 색(4색 중)을 고름. 틀리면 차례 1회 건너뜀.
- **내려**: 비공개 투표(자기 자신 제외), 소유자는 2표. 최다 득표자 차례 1회 건너뜀(동점이면 추첨).
- **변환: 도깨비/포/폰**: 획득 즉시 대기 중인 일반말 하나가 변환됨.
  - 도깨비: 던지기와 별개로 매 차례 한 번 도/백도 1칸 이동(던지기로도 움직일 수 있음).
  - 포: 매 차례 한 번, 가는 방향의 **직선** 위에서 말이 있는 칸을 **정확히 하나** 넘어서 벽(직선의 끝)까지 원하는 칸으로 이동.
  - 폰: 윷을 던질 때마다 자동 1칸 전진, 직접 조작 불가.
- **안개**: 능력 버튼으로 발동, 소유자의 두 차례 동안 유지. 다른 플레이어는 자기 말에서 2칸 이내의 상대 말만 보임.
- **알까기**: 내 말과 노릴 적 말을 고르면 50% 명중(적 말뭉치 사망) / 35% 빗나감 / 15% 내 말이 떨어짐. 차례 소모. (실제 물리 알까기는 아님)
- **언제부터 착각한 거지?**: 상대 증강 하나를 3라운드 동안 '고양이'로 바꿈(이미 쓴 증강 제외).
- **윷을 잘 던져봐**: 윷을 던져 걸 이상이 나오면 명중, 상대는 차례 2번 건너뜀.
- **천마군림보 - 달걸음**: 판 전체가 출발점-왼쪽 위 대각선을 기준으로 좌우 반전되어, 출발점에서 **왼쪽(19번 칸 방향)** 으로 출발해 반대로 한 바퀴 돕니다. 지름길(15번 모서리→중앙→5번, 10번 모서리→중앙→출발점)도 거울처럼 뒤집힘. 백도는 원래 방향으로 한 칸.
- **말이오? 파티**: 함정 6개(사망 3, 3칸 후퇴 3)와 보상 4개(3칸 전진)를 무작위 칸에 설치. 설치 위치는 소유자에게만 보이고, 소유자는 함정에 면역(보상은 누구나).
- **김첨지**: 소유자의 6차례 안에 완주하면 승리. / **중전마마**: 10번 칸(좌측 상단)에서 시작, 죽으면 탈락, 12번 던지면 승리, 다른 말이 완주할 때마다 목숨 +1(죽으면 목숨을 쓰고 부활).
- **마신 소환**: 광신도는 **판 위에 있는 말만** 의식 코인을 줍니다(대기 중이거나 완주한 말은 제외).
- **살인**: 모두 체력 3, 소유자가 잡을 때마다(말뭉치 단위) 체력 1 감소. / **네크로맨서**: 탈락자를 대기 말 전부로 부활. / **메아리의 형상**: 모든 차례가 두 번씩.
- **승부다!**: 지목된 플레이어가 자기 차례 3번 안에 완주 못 하면 탈락, 완주하면 도전자 탈락.
- **영역 전개**: 말 하나를 고정, 소유자의 두 차례를 버티면 승리, 그 말이 죽으면 탈락.
- **카니발리즘**: 내 말 위로 이동하면 내 말이 죽고 추가 던지기 1회.
- **순위전 전용**: 계획대로(최종 순위를 1위부터 차례로 예측), 동메달(즉시 3위, 게임에서 빠짐), 취~소(확정된 모든 승리 취소 후 복귀).

## 알까기 (물리)
- 내 말을 선택한 뒤 판 위에서 뒤로 당겼다 놓으면 반대 방향으로 발사됩니다(길게 당길수록 강함). 서버가 마찰·충돌을 계산해 모두의 화면에 같은 움직임이 재생됩니다.
- 적 말(연쇄 충돌 포함)을 맞혀야 하며, 못 맞히면 내 말은 사망합니다. 멈춘 뒤 한 칸 거리(약 16) 안에 칸이 있으면 가장 가까운 빈 칸(또는 같은 주인 칸)에 서고, 없으면 사망합니다. 밀려난 말도 동일합니다.

## 림버스 컴퍼니 팩 (증강 11개)
범용: 라만차랜드 · K사 · 대호수의 규칙 · 변환 루치오/발렌치나/군주/와일드헌트 · 소속 중지/T사 / 시작 전용: 소속 약지 · 소속 검지.
해석한 부분(기획과 다르면 알려주세요):
- 라만차랜드: 4개 면 중 하나(모서리 포함)가 랜드. 랜드 밖 혈귀는 매 차례 피 1씩(가장 먼 말부터) 소모, 피가 없는 말은 쇠약(이동 1칸·잡기 불가). 랜드 안에서 죽은 말(누구든) 자리에 피주머니, 혈귀가 아닌 말이 밟으면 둘 다 사망·피주머니 주인 피 +1.
- K사/와일드헌트: '죽음'은 대기칸 복귀이므로 부활은 죽은 자리에서 일어납니다. 와일드헌트 부활은 차례를 소모하지 않습니다.
- 대호수의 규칙: 규칙 위반은 위반자의 차례 중 판정되며 차례당 한 번씩 적용. 위반자에게만 규칙이 공개됩니다. '적 2명'은 적 말 2개 이상으로 해석.
- 소속 중지: 이동으로 잡혔을 때만 발동(상대 진행은 내 선택이 끝날 때까지 대기). 죽은 자리 쪽 최단 경로로 2칸.
- 소속 검지의 '대각선 이동 가능한 칸'은 모서리(5·10)와 정중앙.
- 변환 말 외형: 군주(붉은 안대+언월도), 루치오(회색 포니테일+지그재그 칼), 발렌치나(붉은 모자+칼 두 자루), 와일드헌트(거친 갈색 머리+관), 흑수(검은 귀).

## 림버스 컴퍼니 팩 2차 (v1.11, 증강 7개 추가)
변환 에이해브 · 변환 싱클레어 · 뒤틀림, 아니면.. (+E.G.O 7종) · 변환 해결사 (+특색 4종, 검은침묵 무기 8종) · 절호의 찬스자나요! · 너무 아름다운 빛이에요 · 저 마티아스가 여러분 가정에 평화를 빕니다.
용어: '사망시킨다'와 '공격한다'는 같은 뜻(공격받으면 죽음). '매턴'은 그 증강 주인의 차례가 돌아올 때, 고래·뒤틀림의 이동은 라운드 시작(시작 플레이어 차례)에 일어납니다.
해석한 부분(기획과 다르면 알려주세요):
- 분류: 에이해브·싱클레어·뒤틀림·주식은 범용, 해결사·마티아스는 시작 전용, 초록빛은 중간 전용으로 두었습니다(원문에 분류가 없어서).
- 에이해브: 고래가 도착한 칸의 모든 말(에이해브 주인 것 포함)이 죽습니다(쪽빛노인 고래는 해결사 주인의 말만 면제). 에이해브가 고래가 있는 칸에 도착하면 '고래를 잡은 것'으로 보고 가스하푼 개화. 작살은 박힌 말이 2번 이동할 때까지 이동 -1, 차례당 1회.
- 싱클레어: 알 상태는 공격도, 잡기도 안 됩니다. 어느 싱클레어는 던진 결과 이내의 칸수를 직접 고릅니다(이동 +1 같은 보너스는 별도).
- 뒤틀림: 말이 죽을 때마다 말 단위로 50/10/40% 판정. 뒤틀림 이동은 일반 이동과 같이 잡기/피격이 적용됩니다.
- E.G.O: 가시 돋친 입맞춤은 출혈만 부여(처치 아님), 출혈은 한 차례마다 줄고 이동 -1. 무한한 궤적은 연속 이동 보너스 최대 +5, 폭풍의 전야 충전은 최대 20. 가라앉은 독백은 다음 이동 1회 -1. 필연적인 균열은 대상의 앞뒤 칸도 공격. 꺼지지 않는 장례식 후퇴는 상대 차례 시작 시 1칸.
- 해결사: 9급에서 시작, 5급부터 +1 이동·뒤로 이동(던진 결과-2), 1급 뒤 3스택이면 특색(붉은시선/노란작살/쪽빛노인 무작위). 증강 획득 시 4% 확률로 검은침묵. 노란작살의 작살 끌기는 대상을 3칸 후퇴시킵니다(잡기 아님). 쪽빛노인은 대호수의 규칙 하나를 무작위로 정해 얻습니다.
- 주식: 앞으로 가는 던진 결과에만 적용, 이동이 0 이하면 움직이지 못합니다.
- 초록빛: 3차례는 주인의 차례 기준입니다.
- 연출: E.G.O 개화·특색·가스하푼·부화·어느 싱클레어·마티아스는 전체화면 연출, 나머지 능력은 보드 위 이펙트와 효과음이 나옵니다. 모든 능력 버튼은 컨셉에 맞는 색·아이콘으로 표시됩니다.
